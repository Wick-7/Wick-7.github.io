Lecture 15：Object Detection

图像分类只输出整张图的一个标签；目标检测要同时回答“是什么”和“在哪里”，输出数量不固定的类别与 bounding box 集合。

1. 任务定义与朴素方案

每个检测结果包含类别分数和四个框参数 $(x,y,w,h)$。真实图像可能有多个物体、尺度差异、遮挡和背景干扰。

Sliding window 可以在不同位置和尺度裁剪图像，再把每个 crop 送入 CNN，但窗口数量巨大，重复计算严重。

检测比分类多出的核心困难不只是四个连续坐标，而是输出集合长度不固定：模型既要判断哪里可能有物体，又要给候选分配类别，还要把多个指向同一物体的预测去重。后面的 proposal、anchor、box regression 和 NMS，分别对应这几个子问题。

2. R-CNN：先找候选区域，再分类

R-CNN 用 selective search 等方法生成约两千个 region proposals，对每个区域独立运行 CNN，再用分类器和 bounding-box regressor 细化预测。

训练和测试都慢，因为同一张图像的不同区域会重复经过 backbone。

Bounding-box regression 通常不是从零“画”一个框，而是预测相对于 proposal 或 anchor 的偏移：中心点移动量按参考框宽高归一化，宽高变化用对数比例表示。这样目标值的尺度更稳定，也把问题变成“把一个大致正确的框修好”。训练时还要按 IoU 把 proposal 划成正样本、负样本或忽略样本；阈值选择会直接改变训练数据分布。

3. IoU 与 NMS

Intersection over Union 衡量预测框与 ground truth 的重叠：

$$ \operatorname{IoU}(A,B)=\frac{|A\cap B|}{|A\cup B|}. $$

同一个物体常会产生许多相互重叠的框。Non-Max Suppression 先保留分数最高的框，再删除与它 IoU 过高的候选，重复直到没有候选。

NMS 是启发式后处理，不是学习出来的规则。阈值太低会把相邻的两个真实物体误删，太高则会留下重复框；类别分开做 NMS 还能避免不同类别的框互相抑制。拥挤场景中，这一步经常是误差来源。

4. Fast R-CNN 与 RoI Pool/Align

Fast R-CNN 先让整张图只经过一次 CNN，再把候选框投影到共享 feature map 上。RoI Pool 把任意大小的区域量化成固定大小的网格，再对每个子区域做 max pooling。

量化会造成边界错位。RoI Align 不做 snapping，而是在连续坐标采样并双线性插值，因此对小目标和精确分割更友好。

5. Faster R-CNN 与单阶段检测

Faster R-CNN 用 Region Proposal Network 从共享 feature map 上预测 anchor 的 objectness 和位置偏移，省掉外部 proposal 算法：

Anchor 是预先放在每个特征图位置上的参考框，通常覆盖多种尺度和长宽比。RPN 对每个 anchor 预测“有没有物体”和框偏移。它把连续的任意框搜索转成一组密集分类与回归问题，但也会制造大量容易的背景 anchor，因此训练时必须采样正负样本，或用 focal loss 一类方法降低容易负样本的主导作用。

单阶段检测器直接在密集网格和 anchor 上预测类别与框，不再分 proposal 和 classification 两个阶段，速度更快，但需要处理极度不平衡的前景/背景样本。

两阶段方法先用 RPN 缩小搜索范围，再对少量 RoI 做更精细判断，通常精度高、对小目标更友好；单阶段方法省掉第二次逐 RoI 处理，吞吐量更高、部署链路更简单。它们的差别主要是候选筛选发生在何处，并不是“是否使用 CNN”。

6. 评估

检测器通常对每个类别单独评估：先按置信度从高到低排列预测，在给定 IoU 阈值下把每个 ground truth 最多匹配一次。重复检测同一物体、类别错误、定位不足、背景误检都会计为 false positive；漏掉真实物体则降低 recall。

随着置信度阈值降低，通常召回率上升、精确率下降，由此得到 Precision-Recall 曲线。AP 是一类的曲线面积，mAP 再对类别取平均。只报一个 mAP 仍可能掩盖问题，因此还应分开观察不同 IoU、目标尺寸和错误类型：低 IoU 指标好而高 IoU 指标差，往往说明“找到了物体，但框得不准”。

7. 本讲总结

目标检测的工程主线是：

$$ \text{候选区域}\rightarrow\text{共享特征}\rightarrow\text{分类+框回归}\rightarrow\text{去重与评估}. $$

下一讲会在此基础上扩展到语义分割、实例分割和姿态估计。
