Lecture 14：Visualizing and Understanding CNNs

训练完成的 CNN 通常只给出一个类别分数，但我们还想知道它学到了什么、依据哪些像素、内部表示是否有语义结构。今天的工具大致分成两类：读取网络已有的激活，以及通过梯度反过来生成或修改图像。

更细一点，可以按问题来选工具：feature map、最大激活 patch 和近邻是在问“网络表示了什么”；occlusion 与 saliency 在问“当前预测对哪里敏感”；feature inversion 在问“这一层保留了什么信息”；activation maximization、DeepDream 和风格迁移则把网络当作一个可微目标，主动寻找满足特征约束的图像。不同工具回答的问题并不相同。

1. 从滤波器和特征空间开始

第一层滤波器常呈现边缘、颜色和简单纹理；高层滤波器的可视化更抽象。分类器前的 feature vector 可以在图像数据集上取 nearest neighbors，也可以用 PCA/t-SNE 降到二维观察类别聚类。

2. 哪些输入区域最重要

给定一个中间神经元或类别分数，记录大量样本中使它激活最大的图像块，可以得到 maximally activating patches。它回答的是“这个单元通常响应什么视觉模式”。

Saliency map 则对输入像素求梯度：

$$ S(x)=\left|\frac{\partial f_c}{\partial x}\right|. $$

梯度绝对值大的位置对当前类别分数更敏感。把 saliency 与 GrabCut 等方法结合，甚至可以在没有像素级标签时得到粗略分割。

Guided backprop 用修改后的 ReLU 反向规则抑制负梯度，得到更清晰的中间特征可视化。

Occlusion 和梯度法各有取舍。遮挡法直接观察移除某块区域后分数如何变化，更接近干预，但每移动一次遮挡块都要做一次前向计算，而且结果受遮挡块大小和填充值影响；梯度法只需一次反向传播，速度快，却只是当前输入附近的一阶局部敏感度。梯度很小不一定表示区域不重要，也可能是模型已经进入饱和区。

因此 saliency 图适合做线索和模型对比，不宜把一张漂亮热力图解释成因果证明。Guided backprop 的图通常更锐利，但它修改了真实反向传播规则，清晰度也不等于忠实度。

3. 通过梯度生成图像

Feature visualization 从随机图像开始，沿目标神经元激活的梯度上升，同时加入自然图像正则化：

$$ x^*=\arg\max_x\left[f_l(x)+R(x)\right]. $$

加入总变分、像素裁剪或多尺度抖动可以抑制噪声和棋盘格纹理。

Adversarial example 也利用同一条梯度，只不过目标是让模型对人眼几乎不变的图像产生错误判断。

这组方法揭示了同一个事实：网络优化的是特征和分数，并不自动带有人类对“自然图像”的先验。若没有正则化，最容易提高分数的往往是高频纹理或重复局部模式，而不是一张人眼看来完整自然的物体图像。

4. Feature inversion 与 DeepDream

Feature inversion 给定一个真实图像的特征向量，寻找另一张图像，使它在特征空间中尽量接近原图，同时加自然图像正则化。这说明特征保留了哪些信息，也揭示了哪些信息在网络中被丢弃。

DeepDream 不从随机图像最大化某个单元，而是在已有图像上反复放大当前网络已经检测到的特征，因此会出现云朵中的动物、建筑等幻觉纹理。

5. Neural Style Transfer

风格迁移把内容图像的高层 feature reconstruction 与风格图像的 Gram matrix reconstruction 结合：

$$ L=L_{content}+\lambda L_{style}. $$

内容特征保留物体布局，Gram 矩阵保留各层通道之间的纹理统计。

若某层特征为 $F\in\mathbb{R}^{C\times HW}$，Gram matrix 可写成 $G=FF^T$。它统计哪些通道经常一起激活，却把具体激活发生在哪个位置求和掉了。因此它很适合表达“笔触、颜色、纹理共同出现的方式”，同时不会强迫生成图复制风格图中的物体布局。

优化一张图像可以实现风格迁移，但每张新内容图都要重新迭代，速度慢；Fast Style Transfer 则预先训练一个前馈网络，用同样的感知损失监督它，把迭代优化变成一次前向推理。前者换内容、换风格都灵活，后者推理快，但经典版本通常要为每一种风格单独训练一个网络。

6. 本讲总结

可视化工具不能直接证明网络“理解”了概念，但能帮助定位模型真正使用的证据、比较不同层的表示，并发现数据偏差和脆弱性。
