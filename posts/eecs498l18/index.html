Lecture 18：Videos

视频可以看成带时间轴的图像序列。模型需要同时理解 appearance 和 motion，还要在可接受的显存与计算量内处理大量帧。

与图像相比，视频的成本会同时随空间分辨率、帧率和时间长度增长。原始视频可能有数分钟、每秒 24–30 帧，而训练常只能看到几秒、低帧率、低分辨率的 clip。因此视频建模首先是一个采样问题：模型看到的时间窗口，决定了它最多能学到多长的动作关系。

1. 视频输入与单帧 baseline

长度为 $T$ 的 RGB 视频可以表示为 $T\times3\times H\times W$ 的张量。

最简单的方法是对每帧独立运行 2D CNN，再平均或投票类别分数。它没有显式建模运动，却常常是第一个应该尝试的 baseline。

这个 baseline 有时出乎意料地强，因为许多数据集可以仅凭场景或物体判断动作，例如泳池暗示“游泳”、乐器暗示“演奏”。这也提醒我们：高分类准确率不一定代表模型真正理解了运动。只有当类别必须依靠方向、速度或动作顺序区分时，时间建模的价值才会明显。

常见训练方法是从长视频随机截取短 clip 并做时间下采样，测试时再从不同时间位置取多个 clip，平均它们的预测。这样能覆盖更多内容，但带来训练/测试不完全一致：训练标签通常继承整段视频的标签，而随机 clip 未必真的包含该动作。

2. Early Fusion、Late Fusion 与 3D CNN

Late fusion 先分别提取每帧特征，最后拼接或池化；early fusion 把多帧堆到输入通道，在第一层卷积混合时间信息；3D CNN 则让卷积核沿时间和空间同时滑动。

3D 卷积的参数量和显存通常更大，但可以在网络早期学习局部运动模式。实际选择取决于数据规模、帧数和算力。

三种融合方式关注的时间尺度不同。Late fusion 复用成熟的 2D 图像特征，计算经济，但在融合前已丢掉精细像素运动；early fusion 能在底层比较相邻帧，却把固定数量的帧塞进通道，时间平移结构不自然；3D CNN 对时空局部模式共享卷积核，表达最直接，但中间 activation 多了时间维，显存和算力开销显著增加。

3. 运动表示与 Two-Stream

光流为每个像素估计从一帧到下一帧的位移向量：

$$ F(x,y)=(u(x,y),v(x,y)). $$

Two-stream 网络让一个 CNN 看 RGB appearance，另一个 CNN 看堆叠光流，再在高层融合。

RGB 分支擅长识别人、物体和场景，光流分支弱化颜色外观，突出移动方向与速度。代价是传统光流通常要预计算、占存储，并且相机运动也会产生大面积光流；它提供的是运动线索，不等于已经分离出物体真实运动。

4. 长期时间结构

3D CNN 和短 clip 模型的时间感受野有限。可以在 CNN 特征之上堆叠 RNN 或 recurrent convolution，让当前状态跨 clip 保存历史信息。

Nonlocal block 则用时空 self-attention，让一个位置直接读取远处帧和空间位置的特征。

I3D 把成熟的 2D CNN kernel “inflate”为 3D kernel，并用图像预训练权重初始化。

SlowFast 网络用慢路径观察低帧率语义，用快路径观察高帧率运动，再通过 lateral connections 融合。

这些方法分别从不同角度扩大时间范围：RNN 把过去压入状态，nonlocal block 允许远距离位置直接交互，I3D 用图像预训练减轻 3D 模型的数据需求，SlowFast 则把低频语义与高频运动分配给不同计算预算。实际瓶颈不只是网络深度，还包括能否在一个 batch 中装下足够长的视频。

5. 从分类到定位

除了短 clip 分类，还可以做 temporal action localization，在长视频中标出动作开始和结束；spatio-temporal detection 则同时预测人物框、时间区间和动作类别。

6. 本讲总结

视频模型的设计空间可以按融合位置和时间范围组织：

$$ \text{单帧}\rightarrow\text{early/late fusion}\rightarrow\text{3D CNN}\rightarrow\text{RNN/attention}\rightarrow\text{时空定位}. $$

工程上先用单帧 baseline，再根据动作是否依赖运动、时间跨度和计算预算逐步增加复杂度。
