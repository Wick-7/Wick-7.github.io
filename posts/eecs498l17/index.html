Lecture 17：3D Vision

二维图像只记录投影后的颜色，三维视觉要恢复形状、深度、相机坐标和物体表面。表示方式的选择会直接决定网络结构、内存开销和损失函数。

单张图像到 3D 本质上是不适定问题：同一幅二维投影可能来自多个尺度、深度和背面形状不同的三维场景。模型无法仅凭像素恢复唯一真值，只能结合透视线索、遮挡、纹理以及训练数据中的类别先验，预测一个最可能的解释。因此漂亮的重建结果也可能更多来自“见过相似椅子”，而非真正观察到了被遮挡表面。

1. 三维形状的表示

课件把常见表示并列展示为 depth map、voxel grid、implicit surface、point cloud 和 triangle mesh。

Depth map 为每个像素附加一个深度值，适合从单张图像预测可见表面，但存在尺度和深度歧义。

Voxel 将空间离散成三维网格，可直接使用 3D convolution，但分辨率提升会带来立方级内存增长。Octree 只在有细节的区域递归细分，降低稀疏空间的存储浪费。

Implicit function 学习一个连续函数 $o:\mathbb{R}^3\to\{0,1\}$ 或 signed distance function，通过查询任意坐标判断点在表面内外。

可以把几种表示的取舍压缩成四个问题。Depth map 与图像网格对齐、预测简单，但只描述当前视角可见表面；voxel 拓扑自由、适合卷积，却被立方级内存限制分辨率；point cloud 存储高效且与 LiDAR 数据天然匹配，但没有表面连接关系；mesh 可直接渲染并表达光滑表面，却要同时处理几何和拓扑；implicit representation 连续、分辨率高，但渲染或导出 mesh 时需要大量坐标查询与后处理。

2. Point Cloud 与 PointNet

Point cloud 是无序点集合。网络必须对点的排列保持不变，PointNet 对每个点独立做 MLP，再用对称的 max pooling 汇聚全局特征。

点云生成需要集合级损失，不能简单按索引比较点。Chamfer distance 通过最近邻匹配预测点和真实点，允许两组点的顺序不同。

Chamfer loss 可微且不依赖点的排列，但只关心最近邻距离，可能允许点聚集在局部区域，也不直接保证表面法向或连通性正确。实际系统常与 coverage、normal consistency 等约束组合，而不能把一个较小的 Chamfer 数值等同于“形状在视觉上完全正确”。

3. Triangle Mesh 与 Pixel2Mesh

Mesh 用顶点和三角形面表示表面，拓扑结构明确、渲染友好，但预测时需要同时决定顶点位置和连接关系。

Pixel2Mesh 从一个椭球初始化 mesh，反复进行 graph convolution 和顶点更新，使网格逐步贴合图像中的物体。

Graph convolution 对每个顶点聚合邻域顶点特征：

$$ f'_i=W_0f_i+\sum_{j\in\mathcal{N}(i)}W_1f_j. $$

从固定初始 mesh 做变形有一个根本限制：连续移动顶点不能改变拓扑，球面无法通过这种方式变成带孔结构。Mesh R-CNN 采用“先预测粗 voxel，再转为 mesh 并细化”的混合路线，先让 voxel 决定孔洞和连通关系，再利用 mesh 提高表面分辨率。

4. 形状评估与坐标系

IoU 适合比较体素或占据网格，但会受到离散分辨率影响；Chamfer distance 对点集的平均最近邻误差敏感，少量离群点可能被平方距离放大；F1 score 在给定距离阈值后同时衡量 precision 和 recall，更强调“有多少表面点在容差范围内”。不同指标会偏好不同的几何性质，所以论文间必须在相同采样方式、阈值和坐标系下比较。

还要区分 canonical coordinates 与 view coordinates。前者把物体对齐到统一坐标系，后者保留相机视角；模型训练和评估必须明确使用哪一种。

5. Mesh R-CNN

Mesh R-CNN 在 2D 检测和实例分割的 RoI 特征上增加 mesh head，输出每个检测物体的 3D mesh。它把二维定位、像素 mask 和三维形状放在一个共享框架中。

训练 mesh 时只用表面 Chamfer loss 容易得到细长、折叠或退化的三角形，因此还要加入边长、法向或平滑正则，让几何结构更规整。这里体现了一个常见原则：任务损失保证“位置接近”，结构正则负责“输出像一个可用的 mesh”。

数据也限制了模型能学到什么。ShapeNet 规模较大但主要是孤立、干净的 CAD 模型和合成视角，与真实照片存在域差异；Pix3D 把真实家具照片与 mesh 对齐，场景更真实，却集中在有限物体类别。对单图 3D 来说，训练集的形状覆盖和相机标定往往与网络结构同样重要。

6. 本讲总结

三维视觉没有唯一的最佳表示：voxel 易处理但耗内存，point cloud 灵活但无拓扑，mesh 结构明确但预测复杂，implicit representation 连续但需要查询和重建。任务目标和计算预算决定表示选择。
