Lecture 11：Training Neural Networks（Part 2）

这一讲继续讨论训练动态：学习率调度、超参数搜索、学习曲线、迁移学习和分布式训练。主线是先把单卡训练跑稳，再扩大数据、模型和设备规模。

1. 学习率调度与早停

固定学习率往往在训练初期太小、后期又太大。常见调度方式包括 step decay、cosine decay、linear decay 和 inverse-square-root decay。

训练时间也需要控制。训练误差持续下降而验证误差开始上升，通常说明过拟合；可以早停，或保存验证集表现最好的 checkpoint。

学习率调度只有与训练总步数一起看才有意义。Cosine schedule 的 $T$、step decay 的里程碑、warmup 的步数都依赖计划训练多久。若中途改变 batch size 或数据集大小，按 epoch 定义和按 optimizer step 定义的 schedule 也会产生不同结果。

早停不是只看最后一个验证点立即终止，因为验证指标本身有噪声。更稳妥的做法是设置 patience、保存 best checkpoint，并同时观察 loss 与目标 metric。

2. 超参数搜索

Grid Search 在每个维度均匀枚举组合；Random Search 随机采样组合，在高维空间通常更有效，因为不是每个超参数都同等重要。

学习曲线是最有价值的诊断工具之一：训练和验证 loss 都高，可能是欠拟合或优化不足；训练 loss 低而验证 loss 高，通常是过拟合；两者都不下降，优先检查学习率、初始化和数据管道。

超参数搜索应优先在对数尺度上进行，因为学习率、weight decay 等参数跨越多个数量级。实用流程通常是：

  1. 先用少量数据或少量 epoch 做 coarse search；
  2. 排除会发散和明显欠拟合的区域；
  3. 在较好的数量级附近缩小范围；
  4. 用完整训练预算复验候选；
  5. 最后只在测试集上评估一次。

如果每次实验同时改变网络、数据增强和优化器，就无法判断提升来自哪里。训练日志、随机种子、配置和 checkpoint 的可追溯性，是超参数优化能否可信的前提。

3. Transfer Learning

视觉任务常用 ImageNet 预训练模型作为起点。数据少时，冻结卷积 backbone，只训练新的分类头；数据更多时，可以逐步解冻并 fine-tune；目标任务与预训练域差异很大时，则需要更多层参与训练。

迁移学习的解释是：前层学习边缘、纹理等通用特征，后层才更依赖原始数据集的类别。

Fine-tuning 时通常给预训练 backbone 更小学习率，给新初始化的 head 更大学习率。若目标数据很少，一开始就全量更新可能迅速破坏已有表示；可以先训练 head，再逐步解冻。还要保证输入归一化和图像尺寸与预训练模型兼容，否则即使权重加载成功，特征分布也会偏移。

4. 数据并行与模型并行

模型并行把不同层放在不同 GPU 上，适合单个模型太大而无法放入一张卡的情况；数据并行在每张 GPU 上复制完整模型，把 batch 切分后并行计算梯度，再进行 all-reduce。

同步数据并行中，每张卡先独立计算局部梯度，all-reduce 后所有副本得到相同平均梯度，再一起更新。理想情况下吞吐量随 GPU 数线性增长，但通信量、输入管道和负载不均会降低 scaling efficiency。模型并行还可能产生 pipeline bubble：某些设备等待前一阶段输出，硬件没有被持续占满。

5. Large-Batch Training

增大 batch 可以提高设备利用率，但梯度噪声变小，通常需要按 batch size 调大学习率，并在训练开始加入 warmup，避免初始学习率过大导致发散。

Linear scaling rule 的直觉是：batch 放大 $k$ 倍后，一次更新聚合了约 $k$ 倍样本，可以尝试把学习率也放大 $k$ 倍。但它只是经验规则，过大的 batch 会减少参数更新次数，还可能进入泛化较差的 sharp solution。Warmup 让模型先在较小步长下建立稳定激活，再逐渐升到目标学习率。

6. 本讲总结

训练系统可以按三个阶段组织：一次性设置、训练动态、训练后处理。学习率和曲线帮助诊断单次训练，迁移学习与分布式训练则决定如何把一个可行实验扩展到更大数据和模型。
